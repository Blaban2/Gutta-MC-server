# Gutta – nettside

Last opp ALT i denne mappen (inkludert den skjulte mappen .github) til et nytt GitHub-repo.

Deretter, i GitHub:
1. Settings -> Secrets and variables -> Actions -> New repository secret:
   FTP_HOST, FTP_USER og FTP_PASS (fra "FTP File Access" i Apex-panelet)
2. Settings -> Pages -> Source: GitHub Actions
3. Actions -> "Oppdater stats og publiser" -> Run workflow

Siden oppdateres deretter automatisk hver time.
